# 주식 리서치 노트

국내주식·미국주식 정보 정리 및 투자 아이디어 기록용 저장소.

## 구조

```
research/
  templates/
    stock-note-template.md   # 종목별 노트 작성 템플릿
  domestic/                  # 국내주식 (예: 005930-삼성전자.md)
  us/                        # 미국주식 (예: AAPL-Apple.md)
  ideas.md                   # 종목을 넘나드는 투자 아이디어, 테마, 메모
```

## 사용법

1. 새 종목을 조사할 때는 `templates/stock-note-template.md`를 복사해
   `domestic/` 또는 `us/`에 `{티커}-{종목명}.md`로 저장한다.
2. 뉴스/실적/공시를 검색해 요약한 뒤 해당 노트에 날짜와 함께 기록한다.
3. 여러 종목에 걸친 테마나 아이디어는 `ideas.md`에 정리한다.
4. 주기적으로 git commit하여 시점별 기록을 남긴다 (판단 변화 추적에 유용).

## 주의

- 여기 기록되는 내용은 공개 자료를 바탕으로 한 개인 리서치 정리이며, 투자 자문이 아니다.
- 데이터는 조사 시점 기준이며 실시간 시세가 아니다.
